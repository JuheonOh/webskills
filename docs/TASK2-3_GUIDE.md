# 📂 WebSkills 프로젝트 과제 실행 가이드

이 문서는 WebSkills 아카이브에 포함된 2016, 2017년도 기능경기대회 과제(Task 3: Client-side Scripting)의 실행 방법과 주요 테스트 포인트, 숨겨진 기능들을 설명합니다.

---

## 🏛️ 1. 2016 전국대회 (서울 아름누리예술재단)

**경로:** `/2016-national/3-ClientSide/index.html`

### 🔑 로그인 정보

- **아이디**: `admin`
- **비밀번호**: `1234`

### 🚀 주요 실행 포인트 & 테스트 방법

1.  **SVG 지도 인터랙션**
    - 서울 지도 위의 각 '구(Ward)'에 마우스를 올리면 색상이 변경됩니다.
    - 구를 클릭하면 하단에 해당 구의 정보와 갤러리가 나타납니다.

2.  **관리자 모드 & 파일 업로드 (핵심 기능)**
    - 우측 상단 `Admin` 버튼을 클릭하여 로그인 창을 엽니다.
    - `admin` / `1234`로 로그인합니다.
    - 로그인 후 상단 콤보박스에서 특정 '구'를 선택합니다.
    - **Drag & Drop**: 내 컴퓨터에 있는 이미지(`.jpg`, `.png`)나 동영상(`.mp4`) 파일을 화면 중앙의 업로드 영역으로 드래그합니다.
    - 업로드가 완료되면 하단 갤러리에 즉시 추가됩니다.

3.  **Canvas 비디오 썸네일**
    - `.mp4` 동영상을 업로드하면, 브라우저가 자동으로 영상을 로드하여 1.5초 지점의 프레임을 캡처합니다.
    - HTML5 Canvas를 사용하여 썸네일 이미지를 동적으로 생성하고 갤러리에 표시합니다.

## ✈️ 2. 2017 지방대회 (Seoul Travel)

**경로:** `/2017-local/3-ClientSide/index.html`

### 🔑 로그인 정보

- 별도의 로그인 기능이 없습니다. (순수 인터랙션 중심)

### 🚀 주요 실행 포인트 & 테스트 방법

1.  **패럴랙스(Parallax) 스크롤**
    - 페이지를 천천히 스크롤해 보세요.
    - 스크롤 위치에 따라 중간의 비행기 아이콘이나 이미지들이 좌우로 회전(`rotateZ`)하며 움직이는 것을 확인할 수 있습니다.

2.  **갤러리 & 다이얼로그**
    - `Photos` 섹션의 사진을 클릭하면 부드러운 애니메이션과 함께 확대된 이미지가 팝업(Custom Dialog)으로 뜹니다.

3.  **슬라이더 애니메이션**
    - 하단 `WorldSkills` 섹션의 파란색 화살표(Prev/Next)를 클릭해 보세요.
    - 슬라이드가 부드럽게 전환됩니다.

4.  **메달리스트 정보 보기**
    - 하단 `Result` 표에서 선수 이름을 클릭하면, 해당 선수의 정보(국가, 메달, 사진 등)가 모달 팝업으로 나타납니다.

## 🏝️ 3. 2017 전국대회 (제주 관광 안내)

**경로:** `/2017-national/3-ClientSide/index.html`

### 🔑 로그인 정보

- **관리자**: `admin` / `1234`
- **일반**: `Join` 버튼을 통해 회원가입 후 로그인 가능

### ⚠️ 주의사항 (WebSQL)

- 이 과제는 **WebSQL** 데이터베이스를 사용합니다.
- WebSQL은 최신 브라우저(Chrome 등)에서 지원이 중단되었거나 보안 문제로 막혀 있을 수 있습니다.
- 실행이 안 된다면 구버전 브라우저나 WebSQL을 지원하는 환경이 필요합니다.

### 🚀 주요 실행 포인트 & 테스트 방법

1.  **데이터베이스 초기화 & 무한 스크롤**
    - 페이지가 처음 로드될 때 `information.json` 데이터를 읽어와 로컬 WebSQL DB에 저장합니다.
    - 스크롤을 바닥까지 내리면 추가적인 관광지 목록이 로딩됩니다 (Infinity Scroll).

2.  **검색 & 자동완성**
    - 상단 검색창에 '박물관', '공원' 등을 입력해 보세요.
    - 글자를 입력하는 순간 DB에서 실시간으로 검색하여 자동완성 목록을 보여줍니다.

3.  **관리자 기능 (Content Editing)**
    - `admin` / `1234`로 로그인합니다.
    - 관광지 목록에서 `더 보기`를 클릭해 상세 페이지로 들어갑니다.
    - 관리자로 로그인한 경우에만 **수정(Modify)** 버튼이 보입니다.
    - 제목이나 내용을 수정하고 저장하면 DB에 반영되어 즉시 업데이트됩니다.

4.  **회원 기능 & 댓글**
    - `Join`을 통해 새로운 계정으로 가입하고 로그인해 보세요.
    - 상세 페이지에서 댓글을 남길 수 있으며, 본인이 작성한 댓글은 삭제 버튼이 활성화됩니다.
    - 모든 데이터는 새로고침해도 유지됩니다 (`LocalStorage` 및 `WebSQL` 저장).
